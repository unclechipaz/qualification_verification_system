# Midlands State University QVS - User Manual

## 1. Quick Verification (Public & Employers)
1. Open the homepage at `http://localhost:8000/`.
2. Enter the **Certificate Number** (e.g. `MSU-2024-BSC-CS-0001`), **Student Number** (e.g. `R201452X`), or **Verification Code** into the search input box.
3. Click **Verify Now**.
4. The system will display the official status:
   - **VERIFIED & VALID** (Green Badge): Certificate is genuine. You can view academic award details and click **Download Verification PDF Report**.
   - **REVOKED** (Red Badge): Certificate has been revoked by the university.
   - **INVALID** (Gray Badge): No matching record exists.

## 2. Using the Live QR Code Scanner
1. Click **QR Scanner** in the top navigation bar.
2. Click **Start Camera** to allow browser camera access.
3. Align the QR code printed on the MSU certificate within the yellow target box.
4. The scanner will automatically extract the code and verify the credential.

## 3. Employer Screening Portal
1. Register or Log in as an Employer (`username: employer1`, `password: EmployerPass123!`).
2. Navigate to your **Dashboard**.
3. View your complete candidate verification screening log.
4. Click **Download Screening History CSV** for internal compliance records.
